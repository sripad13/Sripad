Privacy-first web analytics · early build

Web analytics without the cookies.

Klixbait is web analytics built around privacy, with live visitor activity and click and scroll heatmaps as core features. It’s an early build: the browser tracker, the collection endpoint and a dashboard preview exist.

Browser tracker

A small tracker with no dependencies that records page views and custom events, and sends anything left over when the page closes.

How it works: Each visit gets a random ID that lasts only for the browser session, so a visitor can’t be followed from one visit to the next.

Privacy

The rules it’s built on

These principles are written into the project and shape every part of it.

No cookies by default

Collection is cookieless by default, with no fingerprinting and no identity that persists across sessions.

Never the content

Form values, passwords, keystrokes and raw page text are never collected.

Advanced tracking is opt-in

Anything beyond the default has to be switched on deliberately and respect consent.

Data kept apart

Customer details are stored separately from the high-volume event data.

Where it stands

Klixbait is an early foundation and isn’t production-ready. Still to come: processing the queue, storing events, wiring real data into the dashboard, heatmaps and production hardening.
