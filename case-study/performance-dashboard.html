A one-page dashboard for every account and site I run, built with AI

Checking several Instagram accounts, Google Analytics and AdSense one by one was eating my mornings. So I built one dashboard that brings them together, using AI instead of a developer.

8amDaily data refresh
3Data sources: Instagram, GA, AdSense
1Page instead of many tabs

The problem

I manage several Instagram creator accounts and a website. Every morning meant logging into separate dashboards, and none of them showed the whole picture side by side.

What I built

  1. One collective Instagram view

    Followers, views, impressions and other available metrics across all accounts, with totals at the top and a country-level breakdown.

  2. Filter by account

    Account logos sit in a row at the top. Click one to filter the whole dashboard to that account, click again to see all.

  3. Website tab

    A TheSportzine.com tab combines Google Analytics and AdSense: views and users per day, channels, top pages and countries.

  4. Daily refresh and easy setup

    Data refreshes once a day at 8am. Accounts and websites can be added or removed from a settings page.

How I built it

I designed it by sharing reference dashboards I liked and iterating on layouts with AI, then built and refined it step by step with AI writing the code. The result is a private tool behind a single login, made for how I actually work.

Measurement note: The dashboard is private because it shows live account data, so it is not shown publicly.
