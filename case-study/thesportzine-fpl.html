A fantasy football dashboard

Your FPL team, live and planned ahead.

The Sportzine FPL is a dashboard for Fantasy Premier League managers. Enter an FPL ID and it shows the squad, live points, rank, fixtures, leagues and player price movement.

Under the hood

How it’s built

JavaScript + ViteA plain JavaScript app with no framework
Pages FunctionsTwo small API routes, one for a manager and one for a league
Public FPL dataReads only what Fantasy Premier League makes public
Short cachingResponses are cached for 45 seconds to stay close to live
ID saved locallyThe manager ID is kept in the visitor’s browser for next time
SVG kitsEvery club kit is a drawn SVG

The site doesn’t log in to a Fantasy Premier League account and doesn’t make transfers for anyone. It is published by The Sportzine, my independent sports site.
