How it’s built

React + TypeScriptThe dashboard interface, built with Vite
RechartsCharts for traffic, growth and revenue
Cloudflare WorkersServes the app and its API
Cloudflare D1Stores daily figures for each account
Cloudflare AccessKeeps the dashboard behind a single login
Scheduled jobsA daily run at 08:00 IST and a check every 15 minutes

I designed it by sharing reference dashboards I liked and iterating on layouts with AI, then built and refined it step by step with AI writing the code. It is a private tool made for how I actually work, and the interface labels any figure that is sample data.
